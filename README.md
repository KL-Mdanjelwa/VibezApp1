🎧 Vibez – Music Streaming Mobile App

Vibez is a music streaming Android application that allows users to discover and browse music using the Jamendo API. The app provides a smooth and modern user experience, with secure authentication and cloud-based data storage powered by Firebase.

👥 Team

This project was developed as part of a team of 4 developers, collaborating on design, development, and feature implementation.

🚀 Features
🔐 User Authentication (Firebase Authentication)
🎵 Music discovery and browsing
🌐 API-driven dynamic content (Jamendo API)
☁️ Cloud database integration (Firebase)
📱 Modern onboarding with swipe interaction
🎨 Clean and intuitive user interface
🛠️ Technologies Used
Kotlin – Android Development
Firebase – Authentication & Database
Jamendo API – Music data integration
Figma – UI/UX Design
